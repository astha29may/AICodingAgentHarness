# output/

Generated harness deliverables for the current project live here, so the repository root stays clean.

| File | Produced by |
| --- | --- |
| `output/PROBLEMSTATEMENT.md` | problem-statement-creation |
| `output/DESIGN.md` | technical-architect |
| `output/TechnicalGaps.md` | technical-architect |
| `output/architecture-first-cut.drawio` | technical-architect |
| `output/IMPLEMENTATIONPLAN.md` | implementation-planner |

Copy the matching template from [templates/](../templates/) (drop `.template`) into this folder to start,
then run the agent. These files are the project's deliverables and are tracked in git.

> The generator-evaluator working files (`gan-harness/feedback/`, `gan-harness/contracts/`,
> `gan-harness/build-report.md`) live under [gan-harness/](../gan-harness/), not here.
